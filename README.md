# Практическое задание №1. REPL

Конфигурационное управление, ИКБО-62-25, вариант №12.

## Общее описание

Минимальный графический прототип эмулятора командной строки.
Заголовок окна содержит имя VFS. Пользователь вводит команду и нажимает
Enter или кнопку «Выполнить». История показывает ввод, результат и ошибки.

## Установка и запуск

Python 3.9, библиотека окна PySide6-Essentials 6.8.3.
Библиотека устанавливается в окружение проекта. Сборка не требуется.
Команды выполняются из корня проекта:

```sh
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
./run.sh
```

В уже настроенном PyCharm выбрать `.venv/bin/python` и запустить `src/main.py`.
Скрипт `run.sh` использует окружение проекта, при его отсутствии - `python3`.
На Windows запускать `python src/main.py` из окружения с зависимостью.

## Команды и настройки

| Команда | Поведение |
| --- | --- |
| `ls [путь]` | Показывает имя команды и список аргументов |
| `cd [путь]` | Показывает имя команды и список аргументов |
| `exit` | Закрывает окно |

`ls` и `cd` принимают не более одного аргумента; `exit` - без аргументов.
Неизвестная команда, лишние аргументы и незакрытые кавычки дают ошибку.
После ошибки диалог продолжается. Пустая строка ничего не выполняет.

Парсер поддерживает кавычки и раскрытие переменных реальной ОС `$HOME`,
`${HOME}` и других. Неопределённые переменные остаются без изменения.
Подстановка выполняется после разбора кавычек, включая одинарные кавычки.

Имя VFS задано константой `VFS_NAME` в `src/shell.py`.

## Функции

| Функция или метод | Назначение |
| --- | --- |
| `main` | Создаёт прототип и запускает окно |
| `parse_command` | Разделяет ввод и раскрывает переменные окружения |
| `Shell.__init__` | Создаёт состояние сеанса |
| `Shell.execute` | Проверяет команду, выполняет заглушку или exit |
| `ShellWindow.__init__` | Создаёт окно, историю, поле ввода и кнопку |
| `ShellWindow.write` | Добавляет обычный текст в историю |
| `ShellWindow.submit` | Принимает ввод, показывает результат либо ошибку |
| `ShellWindow.run` | Показывает окно и запускает цикл событий |

`CommandError` - ошибка команды, отображаемая в окне.
Тесты находятся в `tests`, исходники - в `src`.

## Интерактивная демонстрация

Вводить команды по одной, подтверждая каждую клавишей Enter:

| Ввод | Ожидаемый результат |
| --- | --- |
| `ls` | `ls: аргументы []` |
| `ls docs` | `ls: аргументы ['docs']` |
| `cd docs` | `cd: аргументы ['docs']` |
| `cd "$HOME"` | Аргумент заменён путём домашней папки пользователя |
| `cd "${HOME}"` | То же раскрытие переменной |
| `cd "my docs"` | `cd: аргументы ['my docs']` |
| `unknown` | Ошибка неизвестной команды |
| `ls a b` | Ошибка количества аргументов |
| `cd a b` | Ошибка количества аргументов |
| `exit now` | Ошибка аргументов, окно остаётся открытым |
| `cd "` | Ошибка незакрытых кавычек |
| `ls` | После ошибок команда снова выполняется |
| `exit` | Окно закрывается |

Пустой ввод также проверить отдельно: диалог должен продолжаться.

## Тесты

```sh
.venv/bin/python -m unittest discover -s tests -v
```

Проверяются заглушки, переменные окружения, кавычки, пустой ввод,
ошибки, exit и интерактивное окно. Тест окна выполняется без вывода на экран.

## Параметры запуска

| Параметр | Назначение | Значение по умолчанию |
| --- | --- | --- |
| `--vfs` | Путь к директории VFS | `examples/vfs/minimal` |
| `--log` | Путь к XML-логу | `logs/commands.xml` |
| `--script` | Путь к стартовому скрипту | Не задан |

```sh
./run.sh --vfs examples/vfs/minimal --log logs/demo.xml --script examples/startup.txt
```

При запуске отображаются заданные параметры. Стартовый скрипт выполняется
построчно; ошибки отображаются, выполнение продолжается. `exit` завершает
сеанс. XML-лог содержит команды, сообщения об ошибках и дату и время.
Лог создаётся заново при запуске. Скрипты запуска находятся в `scripts`.

## Виртуальная файловая система

Источник VFS - директория на диске. При запуске её содержимое читается в память.
Файлы и директории источника не изменяются. Символические ссылки и специальные
файлы не поддерживаются. Отсутствующий путь, файл вместо директории и ошибки
чтения приводят к сообщению об ошибке загрузки.

Примеры: `examples/vfs/minimal`, `examples/vfs/multiple`, `examples/vfs/deep`.
Скрипты `scripts/vfs-*.sh` запускают эти варианты и проверяют ошибки загрузки.
`examples/vfs-startup.txt` содержит команды и ошибочные вызовы.

`VirtualFileSystem.__init__` загружает данные, `add_entry` сохраняет объект
в памяти, `resolve` нормализует виртуальный путь, `get` возвращает объект,
`children` возвращает содержимое директории.
